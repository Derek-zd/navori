目标：单容器启动，UI 可访问，登录可用。

前置条件：M0 完成（本文档 + API 契约 + 测试策略）。

| # | 验收项 | 验证方式 | 通过标准 |
|---|---|---|---|
| M1.1 | 服务启动 | 启动二进制/容器 | /api/system/health 200 |
| M1.2 | UI 可访问 | 浏览器打开 | 内嵌 SPA 渲染 |
| M1.3 | 登录 | 表单登录 | Set-Cookie navori_token；/api/auth/me 返回用户 |
| M1.4 | 首启 bootstrap | 首次启动 | 生成 admin 初始密码 + data/master.key（0600） |
| M1.5 | 双后端迁移 | DB_DRIVER=sqlite / mysql 各启一次 | 11 张表迁移成功 |
| M1.6 | reaper 空跑 | 启动（无在途 run） | 不报错 |
| M1.7 | 容器构建 | docker build | 镜像含 git/docker(podman)/kubectl |

## M2 — 仓库 + 触发

目标：任意 git 仓库接入，push 触发 run。

前置条件：M1 通过。

| # | 验收项 | 验证方式 | 通过标准 |
|---|---|---|---|
| M2.1 | 添加仓库 | 表单录入 HTTPS/SSH | clone 成功 |
| M2.2 | 扫描 | 手动扫描 | 探测出 Dockerfile，scanStatus=done |
| M2.3 | 手动运行 | 点「运行」 | 触发 run（git 步骤执行） |
| M2.4 | GitLab webhook | 模拟 GitLab push | 命中分支触发 run |
| M2.5 | 通用 webhook | 模拟通用格式 | 命中分支触发 run |
| M2.6 | 去重 | 同 sha 连推两次 | 第二次 skipped |
| M2.7 | 分支规则 | 配多条规则 | 命中/顺序/浅合并正确 |
| M2.8 | secret 校验 | 错误 token | 拒绝 |

## M3 — 构建推送

目标：仓库 → 镜像按模板 tag 推送成功。

前置条件：M2 通过。

| # | 验收项 | 验证方式 | 通过标准 |
|---|---|---|---|
| M3.1 | registry 校验 | 填错误凭据点 test | E_CONNECT_FAILED |
| M3.2 | 构建 | 触发 run | docker build 成功 |
| M3.3 | tag 模板 | 观察镜像名 | 变量/字面量/清洗/{var.KEY} 正确 |
| M3.4 | 推送 | 观察 registry | 镜像 {registry}/{ns}/{image}:{tag} 存在 |
| M3.5 | 状态机 | 触发成功/失败 run | run/steps 状态正确 |
| M3.6 | SSE 日志 | 打开 run 详情 | 实时按行输出 |
| M3.7 | 停止 | 构建中点停止 | build 进程组被杀 |
| M3.8 | 重启 reaper | 构建中重启服务 | in-flight → failed |
| M3.9 | 重跑 | 历史 run 点重跑 | 同 commit 同配置复现 |

## M4 — 部署 + 审批 + 通知

目标：镜像更新 → 就绪；需审批则等待；跑完收到通知。

前置条件：M3 通过。

| # | 验收项 | 验证方式 | 通过标准 |
|---|---|---|---|
| M4.1 | kubeconfig 校验 | 填错误 kubeconfig 点 test | E_CONNECT_FAILED |
| M4.2 | 部署 | 触发 deploy | set image → rollout → Pod 就绪 |
| M4.3 | 回滚 | 让部署失败 | 非首次自动 rollout undo |
| M4.4 | 审批 | approval=true 触发 | 等待审批 → 通过/拒绝 |
| M4.5 | 审批幸存 | awaiting_approval 时重启 | 重启后仍可审批 |
| M4.6 | 通知 | run 到终态 | 收到 HMAC 签名 webhook |
| M4.7 | 通知失败 | 通知地址不可达 | 记日志不阻断 run |
